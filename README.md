# Programowanie rozproszone i równoległe - Uniwersytet Jagielloński
## Opis przedmiotu
- Przedmiot Programowanie Równoległe i Rozproszone wprowadza w zagadnienia projektowania, implementacji i analizy wydajnych aplikacji działających w środowiskach wielordzeniowych i rozproszonych.

## Zadania
### Zadanie 1
- Implementacja programu równoległego przy użyciu MPI (C/C++).

### Zadanie 2
- Wykorzystanie Java Threads do stworzenia aplikacji równoległej.

### Zadanie 3
- Przykład programowania równoległego w OpenMP (C/C++).

Każde z zadań kładzie nacisk na praktyczne wykorzystanie narzędzi do równoległości lub rozproszenia, a także na analizę wydajnościowych aspektów otrzymanych rozwiązań.
